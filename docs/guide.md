## Введение

**AzimuthWebSuite** — браузерное приложение для работы с гидроакустической системой позиционирования **Zima2 USBL**. 

### Основные сценарии использования

- **Поиск и отслеживание подводных объектов** — маяков-ответчиков, установленных на ТНПА, водолазов, стационарные объекты
- **Навигация ТНПА** — отображение положения относительно судна в реальном времени
- **Работа без GNSS** — определение позиции судна по опорным маякам с известными координатами (режим ⚓)
- **Калибровка антенны** — компенсация инструментальных ошибок USBL-антенны
- **Анализ точности** — расчёт DRMS по трекам маяков
- **Документирование работ** — запись логов, экспорт треков, отметка находок (POI)

### Системные требования

- Браузер на базе Chromium (Chrome 89+, Edge 89+, Opera 75+)
- Web Serial API (включён по умолчанию)
- Разрешение экрана от 480×800 (адаптивный дизайн)

## Установка и запуск

### Онлайн-версия

Откройте в браузере: `https://docs.unavlab.com/AzimuthWebSuite/`

### Локальный запуск

1. Скачайте все файлы из репозитория
2. Поместите в одну папку
3. Откройте `index.html` в браузере

> Сервер не требуется. Приложение работает полностью на клиенте.

### Android

Используйте [UCNL Launcher](https://github.com/ucnl/UCNL_Launcher) — обёртку WebView с поддержкой Web Serial API.

## Интерфейс

### Мастер начальной настройки

При первом запуске приложения автоматически открывается мастер настройки. Он помогает быстро сконфигурировать режим работы антенны без изучения всех настроек.

Мастер состоит из двух, трёх или четырёх шагов в зависимости от выбранного режима.

#### Шаг 1: Режим антенны

| ![img](https://github.com/user-attachments/assets/b730f3d8-09aa-4dfa-a3a8-aa492422d103) |
| :---: |
| _Мастер настройки — выбор подвижности антенны_ |

- **Неподвижна** — антенна зафиксирована (пирс, стоящее судно). Можно работать в метрических координатах X, Y, Z без топопривязки.
- **Движется** — антенна на подвижном судне. Требуется внешний GNSS-компас.

#### Шаг 2: Опорные маяки

<!-- TODO: добавить скриншот шага «Опорные маяки» -->

Мастер спрашивает, есть ли маяк с известными координатами, который можно использовать как **опорный**.

- **Нет** — работа в обычном режиме (географический или декартов).
- **Да, буду использовать ⚓** — включается режим **«⚓ По опорным маякам»**. Позиция судна вычисляется по известному маяку без GNSS. Мастер завершается сразу, и открывается панель **«⚓ Опорные маяки»** для ввода координат.

> Опорный маяк — это маяк-ответчик, координаты которого **точно известны** (например, установлен на дне в известной точке или на буе с известной позицией).

#### Шаг 3а: Координаты (для неподвижной антенны)

Если антенна неподвижна, мастер предлагает выбор:

- **Нет, работать в метрах X, Y, Z** — включается декартов режим. Антенна считается в точке (0, 0, 0), координаты маяков отображаются в метрах: X → вправо, Y → вперёд, Z → глубина. Топопривязка не требуется.
- **Да, сейчас введу** — включается географический режим и сразу открывается панель ручной топопривязки для ввода координат и курса.

#### Шаг 3б: GNSS-компас (для подвижной антенны)

Если антенна подвижна, мастер предлагает подключить внешний GNSS-компас:

- Выберите **скорость порта** (4800–115200 бод, по умолчанию 38400)
- Нажмите **📡 Подключить и проверить**
- Статус покажет результат подключения: «✓ Подключен» или «✗ Не подключен»
- Нажмите **Готово** для завершения настройки

#### Завершение

На последнем шаге доступна опция **«Больше не показывать»** — мастер не будет открываться при следующих запусках.

Вызвать мастер повторно можно через **🔧 Инструменты → ⚙ Мастер настройки**.

## Подключение оборудования

### Zima2 USBL

1. Подключите Zima2 к USB-порту (или через преобразователь RS-232/RS-422)
2. Нажмите **🔌 AZM**
3. Выберите порт в диалоге браузера
4. Скорость: **9600** бод (по умолчанию)
5. После подключения автоматически запросится информация об устройстве
6. После получения информации автоматически запустится опрос маяков

> **Важно:** Не отключайте питание Zima2 во время опроса. Если опрос активен, индикатор мигает жёлтым.

### Внешний GNSS-компас

1. Подключите GNSS-приёмник ко второму порту
2. Нажмите **📡 GNSS**
3. Выберите порт
4. Скорость по умолчанию: **38400** бод (настраивается в ⚙ Настройки)

**Поддерживаемые сообщения NMEA 0183:**

- `$xxRMC` — координаты, скорость, курс
- `$xxHDT` — истинный курс (предпочтительный)
- `$xxHDM` — магнитный курс

## Топопривязка

Для отображения маяков в географических координатах необходима топопривязка — координаты и курс антенны.

### Автоматическая топопривязка

При подключении внешнего GNSS-компаса позиция и курс обновляются автоматически.

### Ручная топопривязка

1. Откройте **🔧 Инструменты → 🌐 Ручная топопривязка**
2. Введите:
   - **Широту** (градусы, -90…+90)
   - **Долготу** (градусы, -180…+180)
   - **Курс** (градусы, 0…360)
3. Нажмите **✓ Применить**

### GPS телефона

Кнопка **📱 GPS** — запрашивает геолокацию устройства (если есть встроенный GPS).

### Сброс топопривязки

Кнопка **🗑 Сброс** — очищает координаты и курс.

## Режим «⚓ По опорным маякам»

<!-- TODO: добавить скриншот панели «Опорные маяки» -->

### Назначение

Режим предназначен для работы **без GNSS**, когда известно точное положение хотя бы одного маяка-ответчика. Позиция судна вычисляется по измерениям до этого маяка (обратная геодезическая задача).

### Когда использовать

- Нет GNSS-приёмника на судне
- Нет возможности выполнить топопривязку (неизвестно положение судна)
- Есть маяк-ответчик с **заранее известными координатами** (например, установлен на дне в известной точке или на буе с известной позицией)

### Быстрый старт

1. При первом запуске в мастере настройки выберите **«Да, буду использовать ⚓»** — приложение переключится в режим и откроет панель **«⚓ Опорные маяки»**. Или откройте панель вручную: **🔧 Инструменты → ⚓ Опорные маяки**.
2. В панели выберите **адрес маяка** (из маски опроса), введите его **известные координаты** (широта, долгота, глубина) и нажмите **➕ Добавить**.
3. Нажмите **▶ Активировать**.
4. Начните опрос маяков (**▶ Опрос** в верхней панели) или запустите воспроизведение лога (**📋 Лог → ▶ Воспроизвести**).
5. После первого измерения позиция судна будет вычислена и отображена на карте. Значок **⚓** рядом с широтой в панели антенны означает, что позиция вычислена по опорным маякам.

### Что отображается в панели антенны

| Строка | Описание |
|---|---|
| Широта / Долгота | **Позиция судна**, вычисленная по опорным маякам |
| ⚓ Точность | `±X.Xм (N×, Nс)` — разброс между опорными маяками, количество источников, возраст. **Показывается только при 2+ опорных маяках** |
| GNSS | **Только если есть GNSS-данные** в логе/порту. Показывает GNSS-позицию |
| Расхождение | **Только при наличии GNSS** — расстояние между позицией по опорным и GNSS |
| Азимут | Курс антенны (от компаса) |

### Точность позиции

- **1 опорный маяк** — точность **не оценивается**. `spread = 0`, строка «⚓ Точность» **скрывается**. Реальная точность зависит от точности USBL и знания координат опорного маяка.
- **2+ опорных маяков** — показывается `spread` (разброс между вычисленными позициями от разных маяков). **Меньше `spread` — выше согласованность.**

### Настройка DH-фильтра судна

Откройте **⚙ Настройки → ⚓ Фильтр судна (DH)**:

- **Макс. скорость судна** (0.5–50 м/с, по умолчанию 2.0) — позиции, перемещение которых превышает эту скорость, отбрасываются.
- **Отвергнутые позиции** рисуются на карте серым крестиком с подписью «ОТВЕРГНУТО».
- **Если позиция судна не обновляется** — увеличьте «Макс. скорость судна».

### Визуализация на карте

<!-- TODO: добавить скриншот карты с опорными маяками и линиями -->

- **Опорный маяк** — выделяется **золотой обводкой** и значком **⚓** рядом с номером
- **Пунктирные золотые линии** — от каждого опорного маяка до позиции судна
- **Круг разброса** — вокруг позиции судна (при 2+ опорных), показывает `spread`
- **Отвергнутая позиция** — серый крестик с подписью «ОТВЕРГНУТО»
- **Трек станции** — строится по вычисленной позиции судна (не по GNSS)

### Ограничения

- **Смещения антенны** (`offsetX/offsetY`) **не применяются** — в этом режиме нет внешней точки отсчёта. Учитывается только угловая поправка `phi`.
- **Несколько опорных маяков** рекомендуется для оценки точности. Их взаимное расположение должно быть **разнесено** (не рядом) — иначе определение позиции будет плохо обусловлено.
- **Курс (heading)** — обязателен. Нужен внешний компас (HDT/HDM/HDG) или встроенный компас антенны Zima2.
- **Калибровки (φ и таблица антенны)** — **сбор данных** недоступен в этом режиме (требуется `geographic`). **Применение** уже загруженной таблицы работает.
- **Опорный маяк** не добавляется в свой трек — координаты заданы пользователем и стабильны.

| Симптом | Причина | Решение |
|---|---|---|
| «Позиция не обновляется» | DH-фильтр отбрасывает всё | Увеличить «Макс. скорость судна» в настройках |
| «Опорный маяк прыгает на карте» | Не установлен anchor | Удалить и заново добавить опорный маяк |
| «Точность всегда ±0.0 м» | 1 опорный маяк | Это норма. Добавить второй маяк для оценки |
| «GNSS-строка не показывается» | Нет GNSS в логе/порту | Это норма. Строка появляется при наличии GNSS-данных |
| «Маяк улетел после DH-фильтра» | Слишком маленький порог | Увеличить «Макс. скорость судна» |
| «Возраст позиции огромный» | Ошибка версии | Обновите приложение (исправлено в 1.4.0) |

## Работа с маяками

### Маска адресов

В настройках можно выбрать, какие маяки опрашивать (адреса 1–16). Маска задаётся числом (сумма битов) или чекбоксами.

### Отображение

- **Цветной круг** — маяк в зоне видимости
- **Серый крестик** — точка отвергнута фильтром
- **Значок ✕** — таймаут (нет ответа > 20 с)
- **Значок !** — устаревшие данные (> 8 с)

### Фильтр маяка (DH)

Настраивается в ⚙ Настройки:

- **Максимальная скорость маяка** — точки с большей скоростью перемещения отбрасываются (0.5–5 м/с)
- Фильтр адаптируется под дальность: на больших дистанциях порог выше

### Сглаживание координат

- На дистанциях **до 1000 м** — медианный фильтр (окно 5 точек)
- На дистанциях **более 1000 м** — без сглаживания

## Калибровка

### Калибровка φ (угловое смещение антенны)

**Назначение:** компенсация угла между нулём антенны и диаметральной плоскостью судна.

**Порядок выполнения:**

1. Откройте **🔧 Инструменты → Калибровки → 🔧 Калибровка φ**
2. Задайте параметры:
   - **От/До угла** — диапазон поиска (обычно 0°–360°)
   - **Шаг** — точность подбора (обычно 1°)
   - **Точек** — максимальное количество измерений (обычно 100)
3. Нажмите **▶ Старт**
4. Выполните манёвр судна (циркуляция вокруг маяка или движение по прямой)
5. Накопление точек остановится автоматически при достижении лимита или нажмите **⏹ Стоп**
6. Подтвердите применение значения φ

**Принцип работы:** перебирает значения φ с заданным шагом, для каждого считает DRMS облака точек маяка, выбирает φ с минимальным DRMS.

> **Важно:** Калибровку φ можно выполнять по двум схемам: в первой схеме маяк неподвижен, а судно маневрируе так, чтобы маяк был виден под разными углами. Во второй схеме антенна должна быть неподвижна, а маяк должен перемещаеться так, чтобы покрыть максимально возможный диапазон углов.

### Калибровка антенны (таблица поправок)

**Назначение:** построение таблицы поправок антенны в зависимости от угла энкодера (0°–360°).

**Порядок выполнения:**

1. Откройте **🔧 Инструменты → Калибровки → ⚠📡 Калибровка антенны**
2. Задайте **шаг угла** (обычно 1°–5°)
3. Нажмите **▶ Старт**
4. Выполните манёвр — судно должно обойти маяк по кругу (или вращайте антенну на месте)
5. Следите за счётчиком точек и центроидой
6. После накопления достаточного количества точек нажмите **🔨 Построить**
7. Если покрытие достаточное — нажмите **✓ Применить**
8. Или сохраните таблицу в CSV: **💾 Скачать**

**Принцип работы:**

- Накапливает точки (heading, измеренный азимут, координаты)
- Вычисляет центроиду — среднее арифметическое координат маяка
- Для каждой точки вычисляет истинный пеленг на центроиду
- Группирует ошибки по секторам энкодера
- Усредняет ошибки в каждом секторе
- Применяет таблицу через AntennaCorrector

> **Требования:** Топопривязка (координаты и курс), неподвижный маяк, манёвр с охватом разных углов.

### Загрузка калибровочной таблицы

В ⚙ Настройки → Смещения антенны → Калибровка:

- **📂 Загрузить** — загрузить CSV-файл с таблицей
- **🗑 Сброс** — очистить таблицу

## Отчёт DRMS

**Назначение:** оценка точности позиционирования маяков.

**🔧 Инструменты → 📊 Отчёт DRMS**

Рассчитывает для каждого маяка:

- **DRMS** (Distance Root Mean Square) — среднеквадратическое отклонение
- **2DRMS** — удвоенное DRMS (≈ 95% доверительный интервал)
- **3DRMS** — утроенное DRMS (≈ 99% доверительный интервал)
- **σX, σY** — стандартные отклонения по осям
- **Центроид** — среднее арифметическое координат

**Формат отчёта:**

```Маяк #1: DRMS=1.23м, 2DRMS=2.46м, 3DRMS=3.69м, σX=0.87м, σY=0.87м, точек=342```

Кнопка **💾 Скачать CSV** — сохраняет полную таблицу с координатами центроидов.

## Настройки

**⚙ Настройки** — модальное окно с секциями:

### Параметры опроса

- **Маска адресов** — какие маяки опрашивать (1–65535)
- **Макс. дальность** — ограничение дистанции опроса (100–5000 м)
- **Солёность** — для расчёта скорости звука (0–40 PSU)
- **Скорость звука** — ручной ввод или авто (по температуре и солёности)

### GNSS-компас

- **Режим компаса** — авто (HDT предпочтительный), только HDT, только магнитный
- **Скорость порта** — 4800–115200 бод

### Смещения антенны

- **X, Y** — линейное смещение антенны от точки вращения судна (метры)
- **φ антенны** — угловое смещение (градусы)
- **Калибровка** — загрузка/сброс калибровочной таблицы

### Режим антенны

- **🌍 Географический** — стандартный режим с топопривязкой (координаты и курс антенны)
- **📐 Декартов (неподвижная)** — антенна считается в точке (0, 0, 0), координаты маяков в метрах (X → право, Y → вперёд, Z → глубина)
- **⚓ По опорным маякам** — позиция судна вычисляется по известным координатам опорных маяков (без GNSS/топопривязки). См. раздел [Режим «⚓ По опорным маякам»](#режим-по-опорным-маякам)

### Фильтр маяка (DH)

- **Макс. скорость** — порог фильтра (0.5–5 м/с)

### ⚓ Фильтр судна (DH)

Подсекция появляется, когда активен режим **«⚓ По опорным маякам»**. Управляет фильтром позиции судна — отсеивает физически невозможные перемещения.

- **Макс. скорость судна** — порог фильтра (0.5–50 м/с, по умолчанию **2.0**). Позиции, перемещение которых превышает эту скорость, отбрасываются.
- **Отвергнутые позиции** — рисуются на карте серым крестиком с подписью «ОТВЕРГНУТО» (для диагностики).
- **Если позиция судна не обновляется** — увеличьте «Макс. скорость судна».

### Треки маяков

- **Макс. точек** — ограничение длины трека (50–10000)
- **Мин. дистанция** — прореживание трека (0.1–50 м)

## Устранение неполадок

### Не удаётся подключиться к Zima2

- Убедитесь, что порт не занят другим приложением
- Проверьте скорость (должна быть 9600 бод)
- Попробуйте переподключить USB-кабель
- Обновите страницу

### Маяки не отображаются

- Проверьте маску адресов в настройках
- Убедитесь, что маяк в зоне видимости (дистанция < макс. дальности)
- Проверьте, что опрос активен (индикатор мигает)

### Нет координат у маяков

- Выполните топопривязку (вручную или подключите GNSS)
- Координаты появляются только после успешного прохождения DH-фильтра

### Приложение тормозит при воспроизведении лога

- Уменьшите скорость воспроизведения до 1x
- Отключите отображение треков (📐 Треки)
- Закройте неиспользуемые панели

### Калибровка не даёт результата

- Убедитесь, что маяк неподвижен
- Накопите больше точек с разных курсов
- Проверьте топопривязку
- Увеличьте шаг угла при построении таблицы

### В режиме «По опорным маякам» позиция не обновляется

- Проверьте, что **опорный маяк добавлен** (панель **🔧 Инструменты → ⚓ Опорные маяки**)
- Проверьте, что **курс антенны (heading) не NaN** — без курса вычисления невозможны. Подключите GNSS-компас или проверьте встроенный компас Zima2
- Проверьте, что **маяк опрашивается** — его адрес должен быть в **маске опроса** (⚙ Настройки → Параметры опроса), и опрос должен быть **активен** (кнопка **▶ Опрос**)
- Увеличьте **«Макс. скорость судна»** в настройках (⚙ Настройки → ⚓ Фильтр судна (DH)). Если порог слишком маленький, DH-фильтр будет отбрасывать все позиции
- **Отвергнутые позиции** видны на карте как серые крестики с подписью «ОТВЕРГНУТО» — если их много, порог точно мал

### Опорный маяк «прыгает» на карте

- Скорее всего **не установлен anchor** (опорная точка мира). Удалите опорный маяк и добавьте заново — при добавлении anchor устанавливается автоматически
- Альтернатива: переключите режим на «Географический» и обратно, или **перезапустите воспроизведение** — в `togglePlayback` anchor тоже устанавливается
- Проверьте, что **`ref.lat/ref.lon`** опорного маяка введены **правильно** (например, в панели опорных маяков)

### Точность всегда ±0.0 м

- Это **норма** при **одном** опорном маяке. `spread = 0` по определению, строка «⚓ Точность» в панели антенны скрывается
- Для **оценки точности** нужны **2+** опорных маяка. Чем дальше они разнесены — тем информативнее `spread`

### GNSS-строка не показывается в панели антенны

- Это **норма**, если GNSS-данных **нет** в текущем логе/порту. Строка «GNSS» появляется **только** при наличии данных
- Если GNSS **есть**, но строка не показывается — проверьте, что режим активен (**⚓ По опорным маякам**) и что GNSS-сообщения **парсятся** (`$xxRMC`)

### Возраст позиции судна показывает миллиарды секунд

- Это **баг** версий **до 1.4.0** — сравнивалось виртуальное время Playback с реальным `Date.now()`
- **Решение:** обновите приложение до **1.4.0**

### В режиме «По опорным маякам» калибровка φ / таблицы не работает

- **Сбор данных** для калибровок в этом режиме **недоступен** — он требует полноценного `geographic` режима (с координатами антенны из GNSS/топопривязки)
- **Применение** уже загруженной таблицы/φ работает — просто загрузите её заранее (в `geographic`), сохраните в настройках, и переключитесь в `beacon_referenced`

### После выхода из режима «По опорным маякам» трек станции «сломался»

- Проверьте **`TrackManager.getAnchor()`** — если координаты остались от опорного маяка, они **сбросятся** при следующем GNSS-обновлении
- Если **не сбрасываются** — обновите страницу или переключитесь в `geographic` принудительно
